# 在 Android 上验证页光相机

使用 JDK 17、Android SDK Platform 36、Build Tools 36.0.0，并启动一台 Android 9 或更新版本的 ARM64 或 x86_64 测试设备。用以下命令构建 debug 应用、安装匹配的测试包并运行仪器测试。

```sh
./gradlew :app:connectedDebugAndroidTest
```

## 验证内容

表格交互另外使用真实触摸注入检查：拖动固定行列标尺改变尺寸、双指放大再缩小、滚动后点击远处单元格。界面回归还覆盖缩放按钮、旋转重开、草稿隔离和写入失败回滚；文件断言检查导出的 XLSX 行高、列宽、缩放与文本编号。


- 图片处理覆盖纸张边角、阴影、旋转、裁切和屏幕条纹。可用同一张有阴影的实拍文档切换原色与增强，对照细小文字、盖章和淡笔画。
- PDF 和 Office 导出用真实文件断言检查页序、可编辑正文、表格行列、前导零、负数和空格。表格测试同时使用完整页面与精确裁到表格的区域。
- 手写校对覆盖同文异位、空识别框、独立尾行、逐项确认、修改保存与复开。需自备图片的现场探针通过设备专用目录读取输入。
- 公开测试夹具为脚本合成的采购单，包括一张平面清单与一张带亮度及倾斜变化的模拟拍照图。可使用本机具备中文的字体生成其他样张。[样张生成器](../tools/qa/make_samples.py)

需要外部样张的探针还要检查实际导出的文件。比较手写结果时，应在识别前逐行转录原稿，对导出的 Word 或 Excel 统计漏行、误字及是否提示人工核对。不同笔迹、逆光和低端手机的耗时需要分别实测。

## 当前验收记录

1.0.0-rc.15 将工作模式前置到相机，文件、文字和表格默认连续拍摄；右下角缩略图进入批次编辑，补拍及取消相册保留材料和模式。首页、文件、工具分开，详情可找到页面编辑、识别与已存稿；PDF 转 Word/Excel 进入校对后导出。视觉统一为暖白、墨色与低饱和棕色，减少框线，缩小工具区，横屏编辑主按钮固定在侧栏底部。

最终 ARM64 release APK 在 Android 16 模拟器、飞行模式和 1.25 倍字体下，**144 项仪器测试全部通过，0 跳过、0 失败**。新增覆盖默认连拍及模式恢复、导入中断后稳定页ID去重恢复、裁切应用与任务完成分离、选第2页提取并保留原稿、搜索直接定位第2张表非首列并在修改后刷新、多选取消删除与批量分类、导出记录持久化和同名文件身份隔离、XLSX未核对与存疑标记，以及横屏主按钮在布局范围内。保留既有书页、阴影、手写、印刷、任务取消、双指缩放及行列尺寸等回归。同一20张公开表格的完整 App 单元格输出与 rc.14 全部一致。APK 215,922,407 字节，普通资产和原生库164项逐项 SHA-256 不变，增加的48 KiB用于代码和界面，不增加模型。

实际模拟器检查包含首页、文件、工具、拍摄类型、真实虚拟相机两次连拍、右下角批次交接、四角调整、补拍和系统相册取消。最终横屏截图确认主按钮完整可见；通过真实系统保存选择器输出两页A4 PDF，成功页可进入导出记录并重开，独立PDF读取确认两页均为595×842点。模拟器的虚拟房间只能验证拍摄和导航，不能替代真实纸面拍摄质量验证。未开展5人新用户可用性测试；未据此宣称多品牌真机或商用全量验收通过。扫码仍为拍照/图片识别，非实时取景识码。文字类型由用户在拍前选择，非自动判定。


1.0.0-rc.14 在转 Excel 前明确选择印刷或手写/混合，并按页检查识别质量；不可靠页会中止整批，保留原图及旧校对稿。旧稿导出需确认，分列、旋转和重开保留模式及质量状态。最终 ARM64 release APK 在 Android 16 模拟器、飞行模式和 1.25 倍字体下，**131 项仪器测试全部通过，0 跳过、0 失败**。包括同一私有三列手写图的印刷模式拒绝/手写模式通过、清晰中英数字印刷表、第二页空白时整批中止、旧稿人工修改保留和完整既有回归。APK 仍为 215,873,255 字节（约 215.9 MB），164 项普通资产与原生库逐项 SHA-256 不变，没有增加模型或字典。详见[识别质量说明](recognition-quality.md)。这些检查不等于荣耀 60 真机复现；缺少用户本次原始照片，尚未验证该具体输入。

1.0.0-rc.13 是保留功能与原始模型的无损精简版本。R8 后的 ARM64 release APK 完整通过 116 项仪器回归，0 跳过、0 失败；实际检查主界面、相机预览和引导开关。20 张公开表格的完整输出与 rc.12 一致。APK 由 231.7 MB 降至 215.9 MB，同模拟器系统 AppBytes 减少约 2.8 MB。包体、安装占用和字节核验方法见[体积报告](apk-size.md)。

1.0.0-rc.12 的 ARM64 构建在 Android 16 模拟器、飞行模式和 1.25 倍字体下通过 116 项仪器测试，完成状态为 116 项成功、0 项跳过、0 项失败。包含真实多指触摸注入、旧有手写与屏纹现场探针，以及本轮三张实拍书页和 20 张公开表格的外部探针。最终横屏对照按钮布局与图片缓存修订隔离修正后，8 项书页、表格和页面编辑专项复测通过，额外检查切换按钮完整可见及选中状态、原稿恢复与编辑持久化。测试不等同于多品牌真机的拍摄与性能验收。
